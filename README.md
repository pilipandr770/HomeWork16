# 🧠 HomeWork16 - Проєкт з Машинного Навчання

**HomeWork16** — це проєкт, що містить модель глибокого навчання для класифікації або іншої задачі штучного інтелекту.

## 🚀 Основні можливості
- 🏋️ **Навчання нейронної мережі** (`train_models.py`).
- 📊 **Збереження історії навчання** (`history.pkl`).
- 🔍 **Використання збереженої моделі** (`cnn_model.h5`).
- 🌍 **Запуск веб-інтерфейсу** для тестування (`app.py`).

---

## ⚙ Встановлення
### 1️⃣ Клонування репозиторію:
```bash
git clone https://github.com/ТВІЙ_ГІТХАБ/HomeWork16.git
cd HomeWork16
```

### 2️⃣ Встановлення залежностей:
```bash
pip install -r requirements.txt
```

---

## ▶ Запуск проєкту
### Запуск навчання моделі
```bash
python train_models.py
```

### Запуск веб-інтерфейсу
```bash
python app.py
```

---

## 📜 Основні файли
- `app.py` — Веб-інтерфейс для взаємодії з моделлю.
- `train_models.py` — Скрипт навчання нейронної мережі.
- `cnn_model.h5` — Збережена модель (нейронна мережа).
- `history.pkl` — Історія навчання.
- `requirements.txt` — Список залежностей.
